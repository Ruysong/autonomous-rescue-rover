- 외부 문서를 기본적으로 검색·열람·참조하지 않는 사용자 승인안을 반영한다(2026-11-03).

## Changes
- 적용 범위와 상대 경로 기준을 `roveraid-team/ros2/`로 명시한다.
- 상위·형제 디렉터리 및 이전 작업 경로의 문서, 내부 링크로 연결된 외부 문서, 이전에 읽은 외부 문서 내용을 기본 판단 근거에서 제외한다.
- 외부 문서는 사용자 명시적 요청의 대상·목적으로만 참조하며 열람·수정·계약 승인을 구분한다.
- 내부 자료가 부족하면 사용자에게 정보를 요청하고 해당 연동의 BLOCKER와 독립적으로 가능한 모의 작업을 구분한다.
- SoT, 서버 연동, 개발 경로·구조도·실행 예시를 새 범위와 일치시킨다.
- 기존 계획·승인·검증·기록과 하드웨어 안전 규칙은 유지한다.

## Impact
- ROS 노드·토픽·메시지·TF·통신 규격·소비자 동작은 변경하지 않는다. 코드 마이그레이션은 필요하지 않다.
- 외부 파일·공유 설정은 변경하지 않는다. 내부 README·과거 기록·fulltext 스냅샷은 이번 수정 대상에 포함하지 않는다.

## Risk
- 외부 문서를 참조하지 않으므로 외부 시스템과의 호환성이 확인되었다고 주장할 수 없다. 실제 연동에 필요한 계약 확인은 별도 작업으로 남긴다.
- 작업 지침의 범위 설정이며 운영체제의 파일 접근 권한을 변경하는 작업은 아니다.
- 현재 모의 구현과 실물 검증의 구분 및 실제 하드웨어 실행 승인 요건을 유지한다.
